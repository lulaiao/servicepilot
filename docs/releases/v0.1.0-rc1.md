# ServicePilot v0.1.0-rc1

This is the first public release candidate of ServicePilot, a reproducible,
local-first after-sales Agent and evaluation platform.

## Highlights

- Deterministic preview-confirm-execute business writes with idempotency,
  optimistic locking and audit evidence.
- Typed MCP services and a bounded Gateway with fault injection and
  lost-response recovery.
- Executable Agent Harness with guardrails, checkpoints, explicit budgets and
  authoritative-state false-success detection.
- Dynamic multi-Agent routing, layered memory, policy retrieval and a
  least-privilege Monitor.
- Reproducible local-model research retaining accepted, bounded and rejected
  results rather than hiding negative experiments.
- Four-case CPU demo and self-contained Trace Viewer requiring no model weights,
  paid API, Docker or GPU.
- 13-entry evidence index connecting claims to reports, manifests, commands and
  ADRs.

## Boundaries

- Synthetic data and in-memory services are the supported default.
- This is not a production payment system and must not be connected to real
  customer or payment data without an independent review.
- Local model findings apply only to the documented hardware, frozen data and
  revisions; they are not general leaderboard claims.
- `v0.1.0-rc1` is a pre-release. No Python package registry publication is part
  of this candidate.
